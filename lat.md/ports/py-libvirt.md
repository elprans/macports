# py-libvirt

The [Portfile](../../python/py-libvirt/Portfile) shadows MacPorts solely to keep the Python binding at version 12.3.0 with the local [[libvirt]] library.

## Difference from MacPorts

The default tree packages 11.8.0. Apart from updated distfile metadata, the subports and Python 3.10 through 3.14 support are unchanged, making this a straightforward coordinated version bump.
