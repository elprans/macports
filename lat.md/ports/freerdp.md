# FreeRDP

The [Portfile](../../net/FreeRDP/Portfile) advances the existing MacPorts FreeRDP recipe from 3.17.2 revision 1 to 3.31.1.

## Difference from MacPorts

Only the release metadata changes materially. Dependencies, the build-type patch, macOS client policy, codec variants, and SDL selection are inherited from the default port, so this is a straightforward version bump.
